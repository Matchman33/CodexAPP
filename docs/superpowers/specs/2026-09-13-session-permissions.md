# 会话权限延迟同步

用户选择：正在执行任务时等待本轮结束再更换权限，不自动停止任务，不重启中继。

- 选中的审批与沙箱设置继续持久化；后端另外记录已确认的实际权限、待生效、同步中及错误状态。
- 空闲且已接续的会话同步权限；正在执行时仅保存选择，结束通知后通过现有命令队列同步，先于排队消息执行。
- 已加载会话直接接续会保留旧配置，因此在确认任务结束后取消订阅，再接续同一会话，比较响应中的实际权限；不删除历史、不发送新提示词。
- 尚未产生历史的新会话不取消订阅；下一轮显式传入沙箱与审批策略。每轮均显式传入策略，避免沿用旧配置。
- 同步失败不能显示已生效，暂停排队消息，保留选择与错误，允许保存重试；断线或只读历史不自动夺取会话占用。
- 前端设置面板和主界面展示当前权限与待生效状态；不把完整沙箱策略、额外目录或私有配置暴露到浏览器。
- 仅验证新增权限同步、直接影响的审批与队列调用方，以及单个手机宽度的浏览器交互；不提交 Git、不重启 4123。
