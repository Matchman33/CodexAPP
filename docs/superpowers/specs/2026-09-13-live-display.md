# 实时消息展示优化

用户已确认同时实施四项：局部流式更新、工具执行过程推送、结构化展示、超长消息最新预览。

- 实时片段只更新所属消息，浏览器每帧合并渲染；保留可视区域节点，不反复卸载再挂载无变化行。
- 工具事件携带 threadId、turnId、itemId；启动、输出、结束沿用同一事件 ID，拒绝过期和无法归属的输出。
- 保留兼容 text，新增命令、退出码、状态、文件变更及工具信息；结构化字段有数量和字符上限，不携带任意原始对象。
- 分页模式的实时内容最多保留开头和最新各 8192 字符，展示最新窗口及位置；完成后的完整内容仍由 Codex 历史分段读取。
- 本地中继与云 Agent 共用实时归一化逻辑。审批、队列、停止、占用和历史分页不改变。
- 验证只覆盖新增流式展示及直接受影响的历史条目转换、分页边界；浏览器默认单个手机宽度，保留可选宽度参数。
- 不自动提交，不中断 4123 或向真实模型发送测试消息。
