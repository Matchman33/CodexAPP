# 使用指南

连接步骤见[项目说明](../README.md)。本指南介绍会话操作、文件与终端功能、配置及远程访问。

## 会话与历史

网页侧栏按项目组织会话，支持搜索、切换和删除。点击新建入口，可选择“在当前项目新建”或“临时会话”。临时会话使用独立工作目录，列表中归入无项目会话。

打开历史会话只读取内容，不会自动接管其他进程的占用。向上滚动或点击向上箭头可加载更早记录；点击回到底部按钮返回最新内容。阅读历史时，流式回复不会强制滚动页面。

网页支持多个会话同时运行，各自保存草稿、图片、等待队列和审批状态。切换或关闭标签不等于停止任务；关闭标签也不删除会话历史。不同手机或浏览器可以独立选择查看的会话。

### 删除会话

点击会话列表中的删除按钮，核对会话名称后确认。删除操作会删除该会话及其派生子会话，不回滚项目文件。运行中的会话需要先结束任务。取消确认不会删除任何内容。

### 删除项目及会话

点击项目分组右侧的删除图标，核对项目名称和路径后确认。删除范围包括全部会话、归档会话及派生子会话，不受搜索筛选影响；电脑上的项目目录和文件保留。删除无法撤销。

后端先检查目标会话、待审批任务与活动终端。存在运行中任务时会阻止删除，需要先停止任务、结束相关终端。删除完成后清理对应等待队列和当前聊天，通过 Codex 的 `project/delete` 移除项目记录。若中途失败，页面报告已删除数量，项目入口保留，未删除会话的队列保持暂停，可核对后重试；已删除记录不会回滚。

项目列表优先使用 Codex `project/list`，旧版桌面分组仅用于兼容不支持项目接口的版本。旧版仍可查看分组，但不能删除项目。本功能需要更新本机中继/Agent；云端网页用户同时更新服务器网页。验证：`node --test tests/projectDeletion.test.mjs` 和 `node tests/threadLifecycle-web.integration.mjs`。

### 会话占用

发送或接续时遇到占用，界面会显示持有进程和受影响会话。可以重试接续、重新检查，或在支持的 Windows 环境中确认结束占用进程。

结束进程可能影响它持有的多个会话。请先核对确认窗口；已经产生的文件改动不会回滚。无法可靠识别进程或没有权限时，界面不会提供结束操作。

设置中的“解除当前会话占用”只释放当前项目服务持有的会话，保留历史与草稿。运行中、等待审批或正在启动的任务需要先结束。释放后，再次发送或继续队列时会重新接续。

## 消息、队列与停止

- 空闲时发送消息会启动任务。
- 任务运行期间，网页的普通消息进入当前会话队列，可查看、取消、暂停或继续。
- 开启“纠偏”后发送内容，会直接补充当前任务，不进入等待队列。
- 点击停止会请求中断当前任务并暂停等待队列，待状态确认后再继续操作。
- 任务失败、会话被占用或 Codex 连接断开时，等待队列暂停，需要检查后手动继续。

排队消息绑定原会话，切换页面不会把消息发送到其他会话。全局最多保留 20 条等待消息，单条文字最多 65536 字符。

刷新或关闭网页不会清空服务中的队列。通过“重启本项目”发起的重启会保存等待消息，恢复后需要手动继续；普通退出或进程崩溃不保证恢复队列。确认超时时先核对历史和队列，再使用界面的重试入口。

## 审批、模型与权限

在审批卡片中批准或拒绝命令、文件改动等请求。一个客户端处理后，其他查看者会同步看到结果。额外权限请求目前只支持拒绝。

在设置中选择模型、思考等级、审批策略及沙箱权限，然后点击“应用”；也可以应用设置并新建会话。模型列表来自电脑端 Codex，支持刷新和自定义模型 ID。思考等级选项随模型能力变化。

| 设置 | 行为 |
|---|---|
| Codex 默认模型 | 使用当前工作目录的有效配置 |
| 模型与思考等级 | 从下一条实际执行的消息生效 |
| 审批策略 | 可选择 `on-request`、`untrusted`、`on-failure`、`never` |
| 沙箱 | 可选择 `workspace-write`、`read-only`、`danger-full-access` |

运行中修改权限不会中断任务或自动批准待处理审批。当前任务结束后同步设置，再执行等待队列；空闲且已接续的会话立即同步。同步失败时，界面显示原因并暂停队列，重新应用设置后手动继续。

设置中的 `never` 只影响审批，不会自动扩大沙箱或操作系统权限。只读查看历史时，修改设置不会自动取得会话写入权。

## 图片与文件

### 发送图片

在网页输入框旁点击图片按钮，选择或粘贴图片。发送前可查看缩略图并删除附件，支持仅发送图片或文字与图片一起发送。图片也可以随消息排队或用于纠偏。

### 预览与下载

助手回复中引用的本地文件会显示预览或下载入口。点击文件链接打开预览；点击下载按钮才开始保存文件。

| 文件类型 | 操作 |
|---|---|
| PNG、JPEG、WebP、GIF | 查看图片预览或下载原图 |
| TXT、Markdown、JSON、CSV、代码 | 查看文本、切换编码、自动换行、语法高亮或下载 |
| HTML、SVG | 查看源码或下载，不作为网页执行 |
| Excel、Word、PDF、压缩包 | 下载后用对应软件打开 |

文本预览最多读取前 1 MiB，下载单文件上限为 32 MiB。带行号或列号的文件链接会定位到对应位置；超出预览范围时会显示提示。

附件可以位于项目内或其他本机目录，但需由会话中的文件引用登记。隐藏目录、常见凭据文件等不会开放下载。文件发生变化、被删除或登记失效时，重新打开会话以获取文件信息。

查看“文件变更”可以展开改动记录和 diff；其中可用附件也提供预览或下载入口。网页不会自动执行文件中的 HTML 或脚本。

## 交互终端

点击网页输入框旁的终端图标打开终端。默认目录为当前会话的工作目录；未选择会话时使用中继配置的默认目录。Windows 使用 PowerShell，Linux/macOS 使用用户 shell。

- 支持连续命令、目录切换、交互输入、ANSI 颜色和 `Ctrl+C`。
- 手机提供 Esc、Tab、方向键、中断、清屏和粘贴按钮。
- 可调整字号，在自适应、80、120、160、240 列之间切换，并横向滚动查看宽内容。
- 多页面可以查看同一终端；只有当前控制页面可以输入和改变终端尺寸，其他页面可明确接管输入。
- 收起面板或网页断线不会结束终端，重连后恢复屏幕内容。
- 点击终端垃圾桶并确认后结束进程，最多同时运行 8 个终端。

终端命令直接使用电脑上服务进程的系统权限，不调用模型，也不受聊天中的 AI 审批和沙箱设置控制。可在中继配置中设置 `"terminalEnabled": false` 并重启服务来禁用。

终端进程不跨服务重启恢复；有活动终端时，“重启本项目”会要求先结束终端。

## 重启项目

使用 `npm start`、`npm run start:agent` 或 Electron 启动后，可在网页设置中点击“重启本项目”。直接使用 `node relay/server.mjs` 或 `node cloud/agent.mjs` 启动时，不提供网页受控重启。

1. 核对当前项目并确认重启。
2. 服务等待当前任务结束，暂停后续队列；等待期间可以取消。
3. 保存等待消息，重新启动项目服务和对应的 Codex 控制进程。
4. 网页自动重连，检查恢复的队列后手动继续。

由本地中继持有服务时，重启本地中继；由 Agent 持有服务时，重启 Agent 及其内置中继。该操作不会重启 Broker、电脑系统或外部映射工具。

## 连接与配置

直连与云端使用同一中继配置时，共享任务、审批、队列和终端。Agent 登录后会使用正在运行的本机中继；本机未启动中继时，由 Agent 启动。

| 文件或变量 | 用途 |
|---|---|
| 项目根目录 `codexapp.config.json` | 源码运行时的中继配置 |
| Agent 配置目录 `relay.config.json` | 独立分发包使用的中继配置 |
| `CODEXAPP_RELAY_CONFIG` | 为中继和 Agent 指定相同的配置文件绝对路径 |
| Agent 配置中的 `relayConfigPath` | 指定 Agent 使用的中继配置文件 |
| `CODEXAPP_DIR` | 指定 Agent 的配置、设备密钥和面板信息目录 |
| `CODEXAPP_DATA_DIR` | 指定会话辅助数据和等待队列恢复记录目录 |
| `CODEXAPP_BROKER` | 指定 Agent 连接的 Broker 地址 |

中继常用配置：

| 字段 | 用途 |
|---|---|
| `host` / `port` | 监听地址和端口，默认 `0.0.0.0:4123` |
| `token` | 直连访问凭据，首次启动自动生成 |
| `codexBin` | Codex 可执行文件路径，空字符串表示自动选择 |
| `defaultCwd` | 默认工作目录 |
| `model` / `reasoningEffort` | 模型和思考等级 |
| `approvalPolicy` / `sandbox` | 审批策略和沙箱 |
| `preventSleep` | 是否阻止 Windows 自动睡眠，默认开启 |
| `terminalEnabled` | 是否启用交互终端，默认开启 |

自动选择 Codex 时，优先使用 PATH 中的独立 CLI，再查找桌面端的可用程序。Windows 桌面缓存程序需包含配套的 `codex-code-mode-host.exe`。没有可用程序时，安装或修复 Codex，或在 `codexBin` 中指定独立 CLI。

模型和权限可在界面中应用；修改端口、路径或终端开关等配置后需要重启对应服务。保持唤醒功能不阻止手动睡眠、合盖或低电量触发的睡眠，也不能唤醒已休眠电脑。

## 远程访问

### NPS/NPC

在服务器运行 NPS，在项目电脑运行 NPC，将公网 TCP 端口转发到本机中继。

Windows 可在项目根目录安装 NPC 文件：

```powershell
npm run npc:install
```

编辑 `conf/npc.conf`，填写服务器地址、连接类型和客户端 `vkey`，然后运行：

```powershell
.\npc.exe -config=".\conf\npc.conf" -log=off
```

| 隧道设置 | 值 |
|---|---|
| 类型 | TCP |
| 目标 | 项目电脑的 `127.0.0.1:4123` |
| 服务端端口 | 自行选择并放行，例如 `18123` |
| 本地代理 | 关闭 |
| PROXY protocol | 禁用 / 0 |

手机选择“中继直连”，填写映射后的访问地址和 CodexApp Token。NPS 的 `vkey`、面板密码和 CodexApp Token 用途不同。

安装命令只安装 NPC 文件，连接、自启和证书由用户配置。在项目目录使用安装脚本时选择 `npc` 模式，NPS 服务端使用独立目录。

### Tailscale Serve

电脑和手机加入同一 Tailscale 网络，并保持连接。在电脑运行中继后执行：

```powershell
tailscale serve --bg 4123
tailscale serve status
```

按命令提示完成授权。手机打开输出的完整 HTTPS 地址，不加 `:4123`，选择“中继直连”并填写 Token。该地址只能在允许访问的 Tailscale 网络中使用。

关闭入口：

```powershell
tailscale serve --https=443 off
```

### frp

使用 frp 将项目电脑的中继端口映射到可访问的入口，手机填写映射地址和 CodexApp Token。中继端口发生变化时，同步修改转发目标。

## 故障排查

| 问题 | 检查方式 |
|---|---|
| 直连网页打不开 | 检查电脑、服务、地址、监听端口及防火墙 |
| Token 无效 | 使用目标电脑当前中继配置中的 Token |
| 云端等待电脑 | 检查 Agent 是否运行并登录相同账号 |
| 账号已停用 | 联系管理员恢复账号后重新登录 |
| HTTPS 页面连不上 HTTP 中继 | 使用协议匹配的访问入口 |
| Codex 未连接 | 检查 Codex 路径、登录或 API 配置及电脑端日志 |
| 任务等待审批 | 在审批卡片处理请求，再观察任务状态 |
| 重启被拒绝 | 检查活动终端、运行任务及启动方式 |
| 队列暂停 | 检查停止、失败、权限同步或占用提示后手动继续 |
| 文件无法预览或下载 | 检查文件是否存在、类型与大小是否支持，重新打开会话获取信息 |

直连健康检查使用 `http://127.0.0.1:4123/health`。云端 Broker 的健康检查为其地址下的 `/health`；电脑 Agent 的状态可在控制面板中查看。
