# 云账号使用

云账号连接支持手机通过 Broker 访问电脑上的 Agent。电脑无需公网 IP，手机无需与电脑处于同一局域网。

## 功能

- 云账号连接免费使用，账号需通过邮箱验证且未被管理员停用。
- 每个账号连接一台在线 Agent，同账号支持多个手机、浏览器或网页标签同时使用。
- 每个客户端独立选择会话，审批结果同步，单个客户端断开不停止电脑上的任务。
- 支持同账号免码连接和配对码连接，配对成功的设备可自动重连。
- 业务消息在手机与 Agent 之间加密传输。
- 直连与云端使用同一中继配置时，共享会话、队列、审批和终端。
- 管理后台支持邮箱验证、账号停用、账号恢复和退出全部设备。

## 启动电脑 Agent

电脑需安装 Node.js、项目依赖以及可使用的 Codex。在项目根目录运行：

```powershell
npm ci
npm run build:web
$env:CODEXAPP_BROKER = "http://你的服务器IP:8787"
npm run start:agent
```

使用 HTTPS 时，将 `CODEXAPP_BROKER` 设置为完整的 HTTPS 地址。该变量需要在启动 Agent 的终端中设置。

电脑控制面板默认位于 `http://127.0.0.1:7878`。端口被占用时会尝试后续端口，以启动输出或配置目录中的 `panel.url` 为准。

## 注册与连接

1. 在电脑面板或云端网页注册账号。
2. 打开验证邮件中的链接。未配置 SMTP 时，由管理员在后台标记邮箱已验证。
3. 电脑面板登录账号，确认云端连接和 Codex 状态正常。
4. 手机浏览器打开同一个 Broker 地址，选择“云账号”并登录同一账号。
5. 根据电脑端的连接模式完成配对，进入会话页面。

Expo 手机端使用 `mobile/src/config.js` 中的 `BROKER_URL`，详见[手机端说明](../mobile/README.md)。

## 配对模式

| 模式 | 操作 |
|---|---|
| 免码连接 | 默认模式，相同账号登录后即可连接 |
| 配对码 | 在电脑面板切换为配对码模式，每台新手机输入面板显示的配对码 |

配对码模式下，未配对的手机不能获取会话内容或执行命令。配对成功后，Agent 保存该设备的公钥；清除浏览器站点数据或更换设备后需要重新配对。

多个手机可以使用同一台电脑显示的配对码。电脑面板展示在线连接数、已授权连接数和设备指纹；同一浏览器的多个标签分别计为连接。

## 多设备使用

同账号的手机可以分别查看不同会话，也可以同时查看同一会话。审批只处理一次，处理结果同步给其他查看者。停止任务作用于目标会话；终端输入由当前控制页面负责。

不同账号分别连接各自的 Agent。一个账号不提供多台电脑选择，也不支持跨账号共享 Agent。需要换电脑时，先退出当前 Agent，再在目标电脑登录。

同一电脑运行不同账号的 Agent 时，需要使用独立的 `CODEXAPP_DIR`、中继配置和端口。云账号隔离不替代操作系统的文件权限管理。

## 账号管理

管理员访问 Broker 地址下的 `/admin`，使用 `ADMIN_TOKEN` 登录。

- **标记验证**：允许已注册用户通过邮箱验证检查。
- **停用账号**：立即断开该账号的云连接，并禁止再次登录。
- **恢复账号**：允许账号重新登录，停用前的令牌仍然失效。
- **退出全部设备**：撤销当前登录令牌，用户可以主动重新登录。
- **删除账号**：删除账号记录并断开相关云连接。

停用或退出云账号不会停止本机任务，不会自动批准审批，也不影响持有有效 Token 的本地直连。找回密码或验证邮箱不能解除账号停用。

## 配置与排查

Agent 配置目录可通过 `CODEXAPP_DIR` 指定。默认位置：

| 系统 | 目录 |
|---|---|
| Windows | `%APPDATA%/CodexApp` |
| macOS | `~/Library/Application Support/CodexApp` |
| Linux | `$XDG_CONFIG_HOME/codexapp`，未设置时为 `~/.config/codexapp` |

`agent.config.json` 保存登录及面板设置，`agent.pairing.json` 保存配对信息。请妥善保管配置目录。

| 现象 | 检查方式 |
|---|---|
| 等待电脑上线 | 检查电脑是否开机、Agent 是否运行并登录相同账号 |
| 账号已停用 | 联系管理员恢复账号，再重新登录 |
| 已有其他 Agent 在线 | 先退出该账号当前连接的电脑 |
| 配对失败 | 核对是否使用目标电脑当前显示的配对码 |
| 中继连接失败 | 检查中继端口、Token、`relayConfigPath` 和 `CODEXAPP_RELAY_CONFIG` |
| 网页在线但 Codex 未连接 | 查看电脑端日志，确认 Codex 路径、登录和 API 配置 |

服务器部署见[部署说明](DEPLOY.md)，会话和终端操作见[使用指南](../docs/使用指南.md)。
