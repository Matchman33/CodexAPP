# CodexApp

通过手机或浏览器远程使用电脑上的 Codex，发送消息、查看回复、处理审批和管理会话。Codex、项目文件和命令运行在电脑上，手机无需登录 Codex。

## 功能特点

- **两种连接方式**：中继直连使用地址和 Token；云账号连接使用账号和设备配对。
- **免费云连接**：同账号支持多台在线 Agent，手机或网页可独立选择目标电脑；管理员可停用、恢复账号。
- **共享任务状态**：直连与云端使用同一中继配置时，共享任务、审批、消息队列和终端。
- **会话管理**：网页支持多会话切换、项目搜索、临时会话、历史分页、删除会话和解除占用。
- **任务控制**：发送消息、流式回复、排队发送、纠偏、停止任务和命令审批。
- **模型设置**：选择模型、思考等级、审批策略和沙箱权限。
- **网页文件工具**：预览图片、文本和代码，定位行号，查看文件变更并下载附件。
- **网页交互终端**：在电脑上运行终端，支持手机按键、缩放、滚动和输入控制权切换。
- **网页外观**：支持浅色、深色、跟随系统、安全 Markdown 和适配手机的聊天布局。
- **Windows 保持唤醒**：服务运行时可阻止系统自动睡眠，屏幕仍可熄灭。

## 使用前准备

电脑需要安装 Node.js 和可正常使用的 Codex，并完成 Codex 登录或 API 配置。使用云端 Broker 时，Node.js 必须支持内置 `node:sqlite`。

下载项目并安装依赖：

```powershell
git clone https://github.com/Matchman33/CodexAPP.git
cd CodexAPP
npm ci
```

电脑与对应服务需要保持运行。默认端口为本机中继 `4123`、Agent 控制面板 `7878`、云端 Broker `8787`。

## 中继直连

适用于局域网，或通过 NPS/NPC、Tailscale、frp 等工具访问电脑。

1. 在项目根目录运行：

   ```powershell
   npm start
   ```

2. 在电脑打开 `http://127.0.0.1:4123`。手机在同一局域网时，使用电脑的局域网 IP，例如 `http://192.168.1.84:4123`。
3. 选择“中继直连”，填写中继地址和启动终端显示的 Token。
4. 连接成功后，新建会话或从侧栏打开历史会话。

`npm start` 会准备终端组件并构建网页本地依赖。首次启动会在 `codexapp.config.json` 中生成 Token。

同一局域网的手机无法连接时，可在管理员 PowerShell 中放行中继端口：

```powershell
New-NetFirewallRule -DisplayName "CodexApp 4123" -Direction Inbound -LocalPort 4123 -Protocol TCP -Action Allow
```

远程访问的配置方法见[远程访问](docs/使用指南.md#远程访问)。

## 云账号连接

适用于手机和电脑不在同一网络的情况。需要可访问的 Broker，部署步骤见[云端部署](cloud/DEPLOY.md)。

在项目根目录启动 Agent，将地址替换为自己的 Broker 地址：

```powershell
npm run build:web
$env:CODEXAPP_BROKER = "http://你的服务器IP:8787"
npm run start:agent
```

1. 打开电脑上的 Agent 控制面板，默认地址为 `http://127.0.0.1:7878`，实际地址以启动输出为准。
2. 注册云账号并完成邮箱验证，然后登录。管理员也可在后台手动标记邮箱已验证。
3. 在手机浏览器打开相同的 Broker 地址，选择“云账号”，登录相同账号。
4. 如果电脑端选择配对码模式，在手机输入电脑面板显示的配对码。
5. 其他手机使用相同账号分别连接、配对，即可同时使用这台电脑。

Agent 的默认模式是同账号免码连接；可在电脑面板切换为配对码模式。同一账号可以在多台电脑登录 Agent，网页顶部或 Expo 客户端的电脑入口可切换目标。单台电脑时自动连接，多台时选择；目标离线后不会自动改连其他电脑。网页每个标签页分别记住所选电脑，切换不停止原电脑的任务。

详细说明见[云账号使用](cloud/README.md)。

## 选择客户端

| 客户端 | 使用方式 |
|---|---|
| 网页 | 浏览器打开中继或 Broker 地址，适用于电脑、iPhone 和 Android |
| Expo 手机端 | 使用 Expo Go 加载项目，或构建独立 App，见[手机端说明](mobile/README.md) |
| Electron 电脑端 | 在桌面窗口中管理 Agent 登录、连接和配对，见[电脑端说明](desktop/README.md) |

网页提供多会话标签、消息队列、文件预览下载和交互终端。Expo 手机端提供聊天、会话列表、模型设置、审批、纠偏和停止任务，回复以可选择文本显示。

## 常用操作

| 操作 | 入口或说明 |
|---|---|
| 新建会话 | 点击新建按钮，网页可选择当前项目或临时会话 |
| 查看历史 | 从会话列表选择目标会话，打开历史不自动接管占用 |
| 调整模型和权限 | 在设置中选择并应用，运行中的任务继续使用已生效设置 |
| 追加消息 | 网页会将运行期间发送的消息加入该会话队列 |
| 纠偏 | 开启纠偏后发送补充要求，作用于当前运行任务 |
| 停止 | 点击停止按钮，等待任务确认结束 |
| 处理审批 | 在审批卡片中批准或拒绝 |
| 重启项目 | 设置中点击“重启本项目”；等待任务结束，活动终端需先关闭 |

完整操作、配置、文件限制和故障排查见[使用指南](docs/使用指南.md)。

## 常用命令

| 命令 | 用途 |
|---|---|
| `npm start` | 启动本机中继和网页 |
| `npm run start:agent` | 启动电脑云 Agent |
| `npm run build:web` | 构建本地网页依赖 |
| `npm run prepare:terminal` | 准备终端运行文件 |
| `npm run npc:install` | 在 Windows 项目目录安装 NPC 文件 |

网页依赖由应用本地托管。需要制作分发包时，见[电脑端打包](desktop/README.md#打包)和[Windows 签名](SIGNING.md)。客户端接口见[协议说明](PROTOCOL.md)。
